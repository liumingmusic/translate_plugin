# 逸译 · 网页翻译（Chrome / Edge 扩展）

一个优雅简洁的浏览器翻译扩展（Manifest V3）：**全文双语对照翻译** + **划词即时翻译**，开箱即用，无需注册即可翻译。

## 功能特性

### 翻译引擎（6 种，可随时切换）
| 引擎 | 是否免费 | 需要配置 | 说明 |
|---|---|---|---|
| Google 翻译 | ✅ 免费 | 无 | 质量佳；大陆网络无代理时自动沿降级链切换 |
| Lingva | ✅ 免费 | 无 | Google 翻译开源镜像（lingva.ml），国内通常可直连，质量同 Google |
| SimplyTranslate | ✅ 免费 | 无 | Google 翻译开源镜像（simplytranslate.org），Lingva 的平行备选 |
| MyMemory | ✅ 免费 | 无 | 独立翻译记忆库，国内直连可用，质量一般，匿名每日有额度限制 |
| 百度翻译 | 免费额度 | AppID + 密钥 | fanyi-api.baidu.com 注册，标准版每月 5 万字（QPS=1） |
| AI 大模型 | 按量计费 | Base URL + API Key | 兼容 OpenAI Chat Completions 协议（OpenAI / DeepSeek / 智谱 GLM / Moonshot 等），可自定义模型与翻译指令 |

> **免费引擎自动互备**：四个免费引擎组成降级链 `Google → Lingva → SimplyTranslate → MyMemory`，一个不可达时自动尝试下一个，并记忆本次会话内可用的引擎，下次直接使用。

### 两种翻译模式
- **全文翻译**：点击工具栏图标 →「翻译此页」，或网页右键 →「翻译整个页面」
  - 原文/译文逐段对照显示，保留网页原有排版结构
  - 悬浮工具栏可切换：`对照` / `仅译文` / `原文`，可一键「还原」
  - 实时进度显示（翻译中 x/y），失败段落会以灰色斜体标出
- **划词翻译**：
  - 选中文本后出现「译」小气泡，点击即在原位弹出结果卡片（含原文、译文、引擎与语种、一键复制、朗读发音）
  - 也可选中文本后使用右键菜单「翻译 "xxx"」

### 多引擎对比翻译
- 在设置页或快捷面板打开「多引擎对比」后，划词翻译会**一次展示多个平台的译文**，逐行对比
- 参与对比的引擎可自由勾选（当前主引擎始终参与）；不可达的引擎会显示具体错误
- 也可随时用右键菜单「多引擎对比 "xxx"」单次触发，无需开启设置

### 单词词典详情（辅助学习）
选中**单个英文单词或中文短词**翻译时，卡片下方自动附带词典面板：
- **音标**：英式 /ˈprəˌnansi.../ 与美式双音标（中文词显示拼音）
- **真人发音**：单词支持英音/美音两种真人语音（有道词典语音），例句可逐句朗读
- **释义**：分词性详细释义，附考试标签（中考 / CET4 / CET6 / 考研 / 雅思…）
- **词形变化**：running / runner 等派生词与变形
- **常用词组**：in the long run 等高频搭配
- **近义词**、**双语例句**（原文加粗 + 参考译文）
- 词典数据来自有道词典网页接口，免费无需配置；句子类选中文本自动跳过词典

### v1.5.3 修复（双向高亮不生效）
- **高亮完全不可见的根因**：高亮样式此前依赖 `color-mix()`，部分浏览器 / 环境不支持时整条声明失效，表现为「选中 / 悬停完全没高亮」。改为 `rgba()` + `outline`，任何浏览器都稳定可见，并加粗描边更醒目
- **事件被页面吞掉**：高亮监听此前挂在 `document` 冒泡阶段，部分网页对 `mouseup`/`mouseover` 调用 `stopPropagation()` 会导致收不到。改为**捕获阶段**注册，确保一定能触发
- **只高亮锚点块 → 不够用**：此前只高亮鼠标起点所在的单个块，选中跨句 / 跨段时体感像「没高亮」。现改为**高亮与选区相交的所有原文↔译文块对**，选中任意范围都能成组对应
- **大页面卡顿**：清除高亮由「全文档 querySelectorAll」改为记录当前高亮元素增量清除，长文页面更顺滑

### v1.5.4 修复（表格 / 列表内译文块「游离」）
- **现象**：全文翻译后，表格单元格（`<td>/<th>`）或列表项（`<li>`）内的译文块偶发跑到表格 / 列表**外面**，破坏段落对照
- **根因**：`wrapBlock` 原用 `insertAdjacentElement('afterend')` 把译文 `<div>` 插到原文块**后面当兄弟**；但 `<td>/<th>` 的父是 `<tr>`、`<li>` 的父是 `<ul>/<ol>`，这些父容器只允许特定子元素，插入 `<div>` 是**非法 HTML**，浏览器自动重排，把译文块游离到表格 / 列表之外
- **修复**：仅对 `<td>/<th>/<li>` 改用「把原文包裹进 `.ety-orig` + 译文 `<div>` 放容器**内部末尾**」，`<p>/<div>/<table>` 等仍用原来的 afterend 兄弟（本就合法）；四种显示模式（对照 / 仅译文 / 仅原文 / 沉浸）的 CSS 同步区分「内部包裹」与「兄弟」两种情况，`restorePage` 增加解包裹逻辑，`collectBlocks` 跳过 `.ety-orig` 避免二次翻译重复
- **顺带**：`.ety-t-block` 译文块背景的 `color-mix()` 也换成 `rgba()`，消除旧浏览器背景不可见的隐患（与 v1.5.3 同因）

### v1.5.5 重构（全文翻译改为「逐句上下对照」）
- **用户诉求**：此前是「整段原文 → 整段译文」两大块，找不到逐行 / 逐句对应，且译文整块下沉；用户要「一行一行对应」的翻译。经确认采用「上下逐句」：每句原文在上、其译文紧随下一行，句句严格对应。
- **核心重构**（content.js + content.css）：翻译 / 对照单元从「块（段落）」细化到「句子」。
  - 新增 `splitSentences`：按中英文句末标点（。！？.!?；; 及换行）切句，无标点长文整段作一句（不误拆）。
  - 新增 `collectSentences` + `wrapSentences`：遍历可见文本节点，把每个文本节点按句拆成「原文句 `<span class="ety-os">` + 译文句 `<span class="ety-t-block">`」成对（`.ety-sent` 包裹），原地替换原文本节点；保留原文容器（`<p>/<td>/<b>` 等）不被破坏。
  - **从根上解决游离**：译文 / 原文句全部用 `<span>`（而非 `<div>`），`<span>` 在任何父容器（含 `<td>/<li>/<b>`）内都是**合法 HTML**；CSS 用 `display:block` 让每句成对成行——既实现句句对应，又彻底规避 v1.5.4 的「div 进受限父被游离」问题（旧 `.ety-orig`/`.ety-inner-pair` 方案因此废弃）。
  - 四种模式 CSS 回归简洁：`trans` 隐藏 `[data-ety-id]`（原文句）、`orig` 隐藏 `.ety-t-block`（译文句）、`immersive` 弱化原文句；`restorePage` 改为把 `.ety-sent` 还原为纯文本节点恢复原文；`MAX_SEGMENTS` 上限 1500→6000（句数远多于段数）。
  - 双向高亮（`pairOf`/`highlightPair`）无需改：译文元素仍是 `.ety-t-block`、原文句带 `[data-ety-id]`，选中 / 悬停任一即可高亮对应句。
- **验证**：jsdom 12 项测试全过——中英文切句正确、无标点不误拆、`<p>/<b>/<td>` 内 `.ety-sent`（span）序列化无异常（HTML 合法）、`restorePage` 原文恢复一致、二次翻译不重复。

### v1.5.7 修复（仅译文布局不一致 + 译文显示设置）
- **仅译文布局不一致的根因**：`仅译文` 模式下原文被隐藏，但译文块 `.ety-t-block` 仍是带「蓝色左边框 + 底色 + 内边距」的盒子，且字号/行高用的是固定值（`0.96em`/`1.65`），与原文块实际字号/行高不同 → 译文看起来是"蓝色盒子"，与原页面排版对不上。
- **修复（content.css）**：`仅译文` 模式下去掉译文块的边框 / 底色 / 内边距 / 圆角，让它回到普通文本流。
- **修复（content.js）**：新增 `syncTransTypo`——`仅译文` 模式下，把每个译文块的 `font-size / line-height / font-family / font-weight / letter-spacing / 上下外边距` **逐个复制自其对应的原文块**（即使原文已 `display:none` 仍能读到计算字号），使译文在字号、行高、字重、段间距上与原页面一致；切回其他模式时 `clearTransTypo` 还原。
- **新增译文显示设置（options）**：
  - 译文文字颜色：默认「跟随原文」（仅译文模式下与原布局同色）；可取消勾选自定义任意颜色。
  - 译文字号：相对原文的倍数滑块（0.8–1.6×，默认 1.0×）。
  - 对照框开关：可关闭对照模式的边框与底色，译文仅用颜色区分。
  - 以上设置通过 CSS 变量（`--ety-t-color` / `--ety-t-scale` / `ety-no-box`）注入，修改后实时作用于正在显示的译文，无需重新翻译。

### v1.5.8 修复（维基百科 / GitHub 等站点全文翻译垃圾过多）
- **根因**：`collectBlocks` 之前对**整个 `document.body`** 做全文翻译。维基百科 / GitHub 这类页面，真正可读的正文只是页面一小块，其余是左侧栏、顶栏、页脚、右侧栏、脚注、导航盒——它们全被翻成双语，挤乱布局、视觉嘈杂。
- **正文区域自动定位 `contentRoot()`**：按优先级命中站点正文容器，只翻正文——维基百科 `#bodyContent` / `#mw-content-text`、GitHub `.markdown-body` / `.comment-body`、通用兜底 `main` / `article` / `[role=main]`，最后才退回整页。
- **站点噪声跳过 `JUNK_SELECTOR`**：正文区域内仍跳过维基脚注 `.reference`、引用列表 `.references`、导航盒 `.navbox`、分类 `.catlinks`、编辑链接 `.mw-editsection`、目录 `.toc` 等；GitHub 标题锚点 `.anchor`。
- **实测（jsdom 模拟典型页）**：维基百科垃圾段从 61%→0%、GitHub 从 36%→0%；正文段落 / 信息框 / 标题全部保留。
- **新增开关（options「翻译与显示」）**：`全文翻译仅翻正文` 默认开启；取消勾选则翻译整页（兼容需要翻全站的特殊场景）。
- **验证**：jsdom 6 项算法测试全过（字号/行高/字族/字重/边距复制正确、隐藏原文仍可读取字号、清空生效、空色值→inherit）；5 个 JS 文件 `node --check` 通过。

### v1.5.9 修复（译文标点在行首换行 / 字号颜色设置入口不清）
- **标点换行根因**：译文块 `.ety-t-block` 会**继承宿主网页**的 `word-break`/`line-break`。很多中文/技术站给 `body`/`article` 设了 `word-break: break-all`，译文块继承后在任意字符（含标点）处硬断行，标点被甩到下一行行首。
- **修复**：给 `.ety-t-block` 强制 `word-break: normal; line-break: strict; overflow-wrap: break-word;`，覆盖宿主继承；`line-break: strict` 启用 CJK 禁则（句号/逗号/顿号等不出现在行首）。
- **设置入口澄清**：设置页「主题强调色」仅为边框/高亮/提示色（容易误以为是译文文字色），已加提示；并明确「全文译文样式」才是改**译文文字颜色/字号**的入口（颜色默认"跟随原文"，需取消勾选才生效）。

## 安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解得的扩展程序**，选择本项目文件夹 `translate_plugin`
4. 工具栏出现「译」图标即安装成功（建议固定到工具栏）

Edge 同理：`edge://extensions` → 开发者模式 → 加载解压缩的扩展。

## 使用

1. **开箱即用**：默认引擎 Google（不可达时自动降级到 Lingva/SimplyTranslate/MyMemory），无需任何配置
2. **快捷面板**：点击图标可切换引擎、源/目标语言、显示方式（即时生效）
3. **深度配置**：快捷面板右上角「⚙ 设置」进入设置页
   - 切换默认引擎、管理各引擎 API Key（每项都有「测试」按钮验证连通性）
   - 配置默认语种、全文显示方式、划词气泡开关、译文颜色
   - 「划词增强」：多引擎对比开关与参与引擎多选、单词词典详情开关

## 文件结构

```
translate_plugin/
├── manifest.json      # MV3 清单
├── background.js      # Service Worker：右键菜单 + 翻译请求路由
├── translators.js     # 翻译引擎层（Google/Lingva/SimplyTranslate/MyMemory/百度/大模型，含多级自动降级）+ 有道词典模块
├── content.js         # 内容脚本：划词气泡/结果卡片 + 全文对照翻译
├── content.css        # 页面注入样式（全部 .ety- 前缀，不污染原页面）

├── options.html/js/css# 设置页
├── icons/             # 图标（make_icons.py 可重新生成）
└── make_icons.py      # 图标生成脚本（Pillow）
```

## 注意事项

- Lingva / SimplyTranslate 是公益镜像服务，偶发限流或 Cloudflare 拦截；遇到时插件会自动切到链路中的下一个引擎
- 百度免费版 QPS=1，全文翻译大页面时较慢属正常现象；重度使用建议配置大模型引擎
- MyMemory 匿名额度约每日 1000 词/IP，超出后可换其他免费引擎/百度/大模型
- 浏览器内置页面（chrome:// 开头）与应用商店页面不支持注入翻译
- 所有 Key 仅保存在本地 `chrome.storage.sync`，不会上传到任何第三方

- **失败段补救**：全文翻译中个别段落失败时，段落右侧出现「⟳ 重试」按钮，可单独重跑降级链，无需整页重翻。
- **文档级上下文**：使用大模型引擎翻译整页时，自动把整页原文作为语境一并提交，缓解逐段翻译丢失前后文、专有名词不一致的问题。
- **翻译本地缓存**：后台对译文做跨会话持久化缓存（FIFO 上限 3000 条），同一页面二次访问秒出，减少重复请求。
